# Housing Portal applications and document uploads

## Checking your housing application status

Open "Applications" in the Housing Portal to see your current status: Draft, Submitted, Under Review, Waitlisted, Offered, or Closed. Each status change also sends an email. "Under Review" typically lasts two to three weeks.

## Document upload fails on the application

If a required document will not upload, check that it is a PDF under 20 MB. Scanned images should be combined into a single PDF. If the upload spinner hangs, refresh the page and try again; partially uploaded files are discarded automatically.

## Which documents are required

A complete application usually needs a photo ID, proof of current address, and income verification. The application page lists the exact set for your case and marks each item as Received or Missing once processed, which can take up to one business day after upload.

## Editing an application after submitting

Once submitted, an application is locked. To change something, open the application and use "Request Change", describe the correction, and a reviewer will either apply it or reopen the form for you. Do not create a second application.

## Withdrawing an application

To withdraw, open the application and choose "Withdraw". This is reversible only by contacting housing staff, so do not withdraw just to make edits; use "Request Change" instead.
