# Housing Portal maintenance requests

## How to submit a maintenance request

In the Housing Portal, open "My Unit", choose "Request Maintenance", pick a category such as plumbing or electrical, describe the problem, and add photos if you can. You will get a ticket number on screen and by email.

## How urgent requests are handled

Mark a request as urgent only for safety issues such as no heat, flooding, gas smell, or a security problem with a door or lock. Urgent requests are routed to on‑call staff and target a same‑day response. Non‑urgent requests target three business days.

## Checking the status of a maintenance request

Open "My Requests" in the Housing Portal to see each request's status: Submitted, Scheduled, In Progress, or Completed. Scheduled requests show the planned visit window. You can add a comment to a request to reach the assigned technician.

## Cannot attach photos to a maintenance request

If photo upload fails, the file may be too large or an unsupported type. Use JPG or PNG under 10 MB each. On a phone, choose "medium" size when the share sheet offers it. You can also submit the request first and add photos as a comment afterward.

## Reopening a completed maintenance request

If a problem is not actually fixed, open the completed request and choose "Reopen" within 14 days, explaining what is still wrong. After 14 days you will need to file a new request and reference the old ticket number.
