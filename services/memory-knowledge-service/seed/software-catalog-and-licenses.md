# Software installation and licenses

## Installing approved software

Open the company software portal to see everything pre‑approved for self‑service install. Click Install and it deploys without an admin password. This is the only supported way to install software on a managed laptop.

## Requesting software that is not in the portal

If you need an application that is not in the software portal, submit a software request with the name, version, vendor, cost, and your business reason. Security reviews it and your manager approves the cost. Do not download installers from the internet in the meantime.

## Requesting a paid license

Some portal apps are free to install but need a paid license assigned before they work fully, and will show a trial or read‑only banner until then. Request the license through the same software request form, referencing the app.

## "You need administrator permission" when installing

Standard users do not have local administrator rights, by policy. If an installer demands admin rights, that software must go through the software request process so it can be packaged and deployed centrally instead.

## Removing software you no longer use

Uninstall unneeded portal apps yourself from the software portal's Installed tab so licenses return to the pool. For anything that will not uninstall cleanly, open a ticket.
