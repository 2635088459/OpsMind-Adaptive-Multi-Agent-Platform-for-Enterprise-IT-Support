# 03 State Machine

## EvaluationDataset

```text
DRAFT
→ REVIEWING
→ PUBLISHED
→ DEPRECATED
→ ARCHIVED
```

非法转换：

```text
PUBLISHED → DRAFT
ARCHIVED → PUBLISHED
DEPRECATED → DRAFT
```

## EvaluationRun

```text
QUEUED
→ RUNNING
→ SCORING
→ COMPARING
→ PASSED
```

失败与中止：

```text
RUNNING → PARTIAL
RUNNING → FAILED
SCORING → FAILED
COMPARING → FAILED
QUEUED/RUNNING → CANCELLED
```

`PASSED`、`FAILED`、`CANCELLED` 是 final state。

## ImprovementCandidate

```text
DRAFT
→ BENCHMARKING
→ PENDING_APPROVAL
→ APPROVED
→ CANARYING
→ PROMOTED
```

异常状态：

```text
BENCHMARKING → REJECTED
PENDING_APPROVAL → REJECTED
CANARYING → ROLLED_BACK
PROMOTED → ROLLED_BACK
```

## Canary

```text
PLANNED
→ ACTIVE
→ EXPANDING
→ SUCCEEDED
```

异常状态：

```text
ACTIVE/EXPANDING → PAUSED
ACTIVE/EXPANDING → FAILED
FAILED → ROLLBACK_REQUESTED
ROLLBACK_REQUESTED → ROLLED_BACK
```
