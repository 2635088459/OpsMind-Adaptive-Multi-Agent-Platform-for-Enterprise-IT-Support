# SPEC-TW-007 — API Contract

## Endpoint

```http
POST /api/v1/tickets/{ticketId}/triage
```

This is a dedicated lifecycle command. The general status-transition API must not perform triage.

## Required Headers

| Header | Rule |
|---|---|
| `Authorization` | Bearer token or approved service identity |
| `If-Match` | Strong ticket version ETag, for example `"7"` |
| `Idempotency-Key` | UUID, unique for this actor and command intent |
| `Content-Type` | `application/json` |
| `X-Correlation-Id` | Optional UUID; generated by the service when absent |

## Path Parameter

`ticketId` is a UUID. Malformed values return `400 VALIDATION_ERROR`.

## Request Schema

| Field | Type | Required | Rules |
|---|---|---:|---|
| `categoryId` | UUID | yes | Active category |
| `subcategoryId` | UUID/null | no | Active and belongs to `categoryId` |
| `priority` | enum | yes | `LOW`, `MEDIUM`, `HIGH`, `CRITICAL` |
| `supportQueueId` | UUID | yes | Active queue authorized for actor |
| `reason` | string | yes | Trimmed, 1–500 characters |

Unknown properties are rejected. The request never accepts `triagedBy`, `triagedAt`, `status`, `version`, or tenant identity.

## Success Response

```http
HTTP/1.1 200 OK
ETag: "8"
Content-Type: application/json
```

## Stable Errors

| HTTP | Code | Meaning |
|---:|---|---|
| 400 | `VALIDATION_ERROR` | Invalid UUID, JSON, enum, length, or unknown field |
| 401 | `AUTHENTICATION_REQUIRED` | Missing or invalid identity |
| 403 | `TRIAGE_NOT_ALLOWED` | Actor role cannot triage |
| 403 | `QUEUE_ACCESS_DENIED` | Actor cannot route to target queue |
| 404 | `TICKET_NOT_FOUND` | Missing or tenant-inaccessible ticket |
| 409 | `INVALID_TICKET_STATE` | Current status is not `OPEN` |
| 409 | `IDEMPOTENCY_KEY_REUSED` | Same key, different canonical request |
| 412 | `VERSION_CONFLICT` | `If-Match` does not match |
| 422 | `TRIAGE_CATEGORY_INVALID` | Missing/inactive category |
| 422 | `TRIAGE_SUBCATEGORY_INVALID` | Missing/inactive/mismatched subcategory |
| 422 | `SUPPORT_QUEUE_INVALID` | Missing/inactive queue |
| 428 | `PRECONDITION_REQUIRED` | Missing `If-Match` |
| 500 | `INTERNAL_ERROR` | Unexpected failure; no partial commit |

Error details must remain stable enough for contract tests and must not expose SQL, stack traces, or cross-tenant information.
